# 勇者小队全灭了 修改器 1.1

Windows 64 位独立窗口工具，需要 .NET Framework 4.x。

> 普通用户请到右侧 **Releases** 下载“勇者小队全灭了修改器-v1.1-发布包.zip”，解压后运行 EXE。绿色 **Code → Download ZIP** 下载的是源码，需要自行编译。

[下载最新版本](https://github.com/Imibichan/annihilated-trainer/releases/latest) · [全部版本](https://github.com/Imibichan/annihilated-trainer/releases)


## 功能

- 调整主角及当前同伴的力量、灵巧、敏捷、魔力，支持 0～99999。
- 按人物记录额外加成；保持工具打开，正常升级后会补回加成。例如正常力量 32 改成 100，正常力量升级至 34 后得到 102。
- “还原正常四维”清除所有支持人物的额外加成，当前队伍按当前等级和正常成长恢复属性。
- F8 或绿色按钮：主角和当前同伴各回复最大生命值的 50%，向下取整，不超过满血，不复活。

## 使用

1. 自行备份存档，打开游戏并进入存档。
2. 运行“勇者小队全灭了修改器.exe”，等待连接。
3. 输入四维，点击对应人物的“应用四维”。从 1.0 升级时，需在 1.1 重新应用一次，才会记录加成。
4. 保持修改器打开，才能在游戏重算属性后继续保留加成。游戏重启后重新连接。

读档、切换人物或升级过程中如提示数据变化，请等待稳定后重新读取。重新读取会覆盖未提交的输入。“还原正常四维”不倒退等级，不修改生命上限、物品或剧情进度。加成通过游戏的本地自定义变量记录，由游戏负责正常存档；工具不直接改写磁盘存档文件。跨保存、退出和重新载入的完整流程尚未单独验证。

## 源码构建

在 Windows PowerShell 5.1 中进入仓库根目录后运行：

```powershell
powershell.exe -NoProfile -File .\Build.ps1 -Target Trainer
powershell.exe -NoProfile -File .\Test-InMemory.ps1
powershell.exe -NoProfile -File .\Test-Growth.ps1
```

构建生成 `Trainer.exe`，可自行重命名。`Trainer.ico` 为编译所需图标。两个测试脚本为离线测试，不连接游戏。
