# 勇者小队全灭了 修改器 v1.4

Windows x64 单机修改器，软件与源码免费分享。v1.4 新增标题菜单的全 CG 鉴赏，可按角色、章节看图和读原作简中对白。存档工具可调整隐藏结局资格。

## 下载和升级

在 v1.4 发布页下载 **Annihilated-Trainer-v1.4.zip**，完整解压到独立文件夹，运行「勇者小队全灭了修改器-v1.4.exe」。发行包已附画廊所需运行环境和源码。[下载 v1.4](https://github.com/Imibichan/annihilated-trainer/releases/tag/v1.4) · [历史版本](https://github.com/Imibichan/annihilated-trainer/releases)

原百度网盘分享的提取码为 `wpaw`。[备用网盘](https://pan.baidu.com/s/1SCNvGLSrBEULi8bZ3gCIfg?pwd=wpaw)

## CG 鉴赏

1. 退出游戏，在修改器的「CG 画廊」页点「启用画廊」。已装旧版并收到提示时点「更新画廊」。
2. 启动游戏，在标题菜单选择「CG 鉴赏」。四位同伴和共通目录共收录 **364 项回忆与画稿、1,054 幅画面**。目录按原剧情路线和触发顺序编排，跨路线登场、随机事件及独立画稿单列。默认隐藏剧透预览。
3. 点对白框可逐句读，也可查看全文或进入剧情分支。「纯看图」显示完整构图，点画面可回到刚才的镜头和对白。浏览画廊独立于正常存档与解锁进度。

画廊从玩家本机的 Steam 游戏读取插画、场景和简中对白。游戏更新后，只要所需菜单及资源结构仍兼容，就可重新生成。想移除入口时，退出游戏并点击「关闭画廊」。[完整使用说明](setup/使用说明.txt)

## 角色、战斗与存档

- 进入游戏存档后连接修改器。可调整主角和当前同伴的力量、灵巧、敏捷、魔力及 SAN，保持修改器打开可在正常升级的基础上维护额外加成，也可一键还原正常四维。
- 按 F8 为存活队员各回复最大生命值的 50%，向下取整，最多回到满血。
- 「存档（含剧透）」页提供备份、恢复及隐藏结局资格调整。写入前请退出游戏、确认 Steam 云同步状态并先备份。需要的后续路线仍由玩家在游戏中完成。

## 构建与验证

在 Windows PowerShell 5.1 中，从仓库根目录执行以下命令。

```powershell
.\Build.ps1 -Target Trainer
.\Test-Gallery.ps1
```

画廊索引生成代码在 `catalog/`，游戏内菜单和构图代码在 `title/`，安装、打包和校验脚本在 `setup/`。本版在已验证的 Steam 构建上实机抽查，并对生成资源的 408 个鉴赏入口和 170 次分支跳转做了回读验证。[构建说明](setup/构建说明.txt) · [验证记录](验证记录.txt)
