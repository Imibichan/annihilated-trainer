勇者小队全灭了 修改器 v1.4 · 构建说明

在 Windows x64 上，从仓库根目录用 Windows PowerShell 5.1 执行 .\trainer\Build.ps1 -Target Trainer。使用成品 ZIP 随附的源码时，从「源码」目录执行同一命令。生成的程序位于 trainer\Trainer.exe。
安装助手使用 Python 3.13、UnityPy 1.25.4 和随包依赖。运行时从玩家本地读取原始标题资源和简中台词，构建标题菜单。游戏无需安装 Python。

从源码重新打包时，准备 Python 官方的 python-3.13.11-embed-amd64.zip，以及包含 UnityPy 1.25.4 完整依赖的目录。已解压成品的 gallery/runtime/Lib 即为该依赖目录。在 PowerShell 7 中进入「源码」目录，选用空目录作为输出目录，执行以下命令。
  ./setup/package.ps1 -RuntimeZip <嵌入版Python的ZIP> -PythonPackages <依赖目录> -AvatarPath ../魔法师头像.png -OutputDirectory <输出目录>
  python setup/archive_release.py <输出目录> <位于输出目录之外的ZIP路径>
第二条命令写入 SHA256SUMS.txt，并重新打开 ZIP 逐项核对。

catalog/gallery.json 保存插画的游戏内地址、逐帧场景、原画尺寸和简中对白的字节位置。重建索引请使用同一版游戏和已安装 UnityPy 依赖的 Python：
  python catalog/inspect_game.py <游戏根目录> <临时目录> --reader-path <UnityPy依赖目录>
  python catalog/build_catalog.py <游戏根目录> <临时目录> catalog/gallery.json
第一条命令同时提取原画和本地化图片的尺寸信息。如果已装画廊，可向第一条命令附加 --stock-catalog <原始catalog.bin路径>，使用受支持的原始索引。
生成楼层和房间的资源引用清单：
  python catalog/backgrounds_render_assets.py <游戏根目录> <临时目录> catalog/gallery.json catalog/backgrounds_assets.json --reader-path <UnityPy依赖目录>
启用时，title/ui_art.py 和 catalog/backgrounds_render.py 从玩家的安装目录读取原画、本地化图和场景，生成带纹理的原生 Unity 界面。
兼容更新时，catalog/compatible_content.py 使用当前 Addressables 登记的文件重新生成插画、场景与简中索引，title/title_bindings.py 按标题控件层级、组件和引用关系定位按钮。确认当前两项原件、生成物和索引记录一致后，安装助手才替换游戏文件。
title/verify_title.py 回读生成的标题资源，检查打开、返回、逐句播放与原画预览。setup/test_setup.py 检查安装、恢复、更新冲突和中断处理。trainer/Test-Gallery.ps1 检查修改器界面与安装助手之间的调用。
路线及章节顺序的生成逻辑在 catalog/story_order.py。画廊修订号位于 setup/gallery_builder.py；已有安装通过这个编号提示更新。
运行存档工具的离线测试时，用环境变量 ANNIHILATED_SAVE_FIXTURE 指向专用测试副本。该测试用例的初始状态为轮回计数 10、勇者和战士通关计数 0、魔法师通关计数 1。发布包不含玩家存档。
