《勇者小队全灭了。》修改器 V1.6.2　验证记录

V1.6.2 回放路径修复

在受 Windows 传统路径限制的进程中运行正式包内的 Python。先确认普通路径写入 262 个字符时会失败，再用 V1.6.1 复现了回放启动器在 shutil.copyfile 写入 .game.building 时的 FileNotFoundError。
在同一环境、同一测试缓存中，V1.6.2 完成 569 个游戏文件的复制及校验。新副本成功迁入 V1.6.1 的主角选择和上次观看位置，并清理了一份完整旧副本和一份复制中断的旧副本。
测试中最长的游戏资源路径为 360 个字符。人为损坏测试副本里的这份资源后，再次启动能从正式安装恢复原始字节，复用同一份副本。实机从继承的「坍塌的天花板」标记进入剧情，确认画面、中文菜单和对白正常。
本次生成 204 个入口、15 项独立画稿。剧情、标题、回放目录字体和资源索引的 SHA-256 与 V1.6.1 正式包生成的结果一致。133 项 Python 测试、3 项原生资源往返测试及 13 组 C# 测试通过。测试前后比对了 575 个 Steam 安装文件、106 个正式存档及设置文件，以及正式游戏的 I2 语言设置，结果一致。

V1.6.1 字体修复
在正式游戏使用简体中文时，将独立回放的剧情语言设为英语。即使另行指定 I2 Language 为简体中文，旧版仍在启动后恢复英语，菜单出现「魔法□」「□士」「僧□」。对同一副本应用语言修复并重启后，「魔法师」「战士」「僧侣」均正常显示。
使用正式包从修改器进入回放，确认简中目录、上次观看标记及「决战之前」的简中正文。另用英语、日语的测试设置启动同一个回放副本，核实「坍塌的天花板」目录和两种语言各自的原作对白；切换语言时复用了同一份游戏资源。
逐项检查 874 条回放菜单选项用到的 401 个不同字符。两套原作菜单字体配合补充字库后均完整覆盖，补充的 115 个字形来自本机原作字库。
分别从本机和测试目录内已使用的 V1.6 副本升级。两处均迁入主角选择与上次观看位置，并清理了原有游戏副本。新版保留了 204 个剧情入口、15 项独立画稿，生成的剧情脚本包与 V1.6 的 SHA-256 相同。
使用发布包运行库执行 130 项 Python 测试和 3 项原生资源往返测试，全部通过。修改器侧通过 13 组 C# 测试。测试后逐一比对本机 Steam 安装的 575 个文件、正式存档及设置的 96 个文件，以及正式游戏的 I2 Language 注册表值，均与测试前一致。

V1.6 基线验证

环境与范围
Windows x64，Steam 构建 26845264，原作资源标识 004a514c06f1f4a7563e5f75c24d55e4。角色和剧情实机验证使用本机游戏资源及独立测试存档。后续游戏构建以实际资源结构、变量可读写结果为准。

回放与更新内容
本次构建生成 204 个剧情入口和 15 项独立画稿。原作新增演出归入相应的现有入口。正式副本内 44 个剧情脚本共 83,352 行，逐行回读与预期一致，涉及 27 个脚本中的 10,479 处编排。本次构建没有因不兼容而隐藏的入口、分支或画稿。
在游戏内分别使用男、女主角进入魔法师第四层「取回魔力」、僧侣第四层「拒绝伸出的手」、僧侣终章「最后一击与告别」。用独立测试进度定位三处变动的演出，核对原作画面、对应的主角差分，以及共用画面。共检查六组角色与场景组合，其余入口进行了脚本和资源验证，未逐场手动通关。
用正式包从已迁移的观看位置打开「坍塌的天花板」，通过原作选项进入轮盘，余额从 999 扣至 997。结算后实际回到了原目录，观看标记仍在该场。
原生指令测试核对了 16 行序列化后的指令与字段，以及资源校验值。两次标题资源往返均核对了 3,835 个无关 Unity 对象的原始字节。

旧版升级与损坏恢复
使用一份已完成和一份准备中断的真实 V1.5 副本重现升级。V1.6 先从当前安装构建并校验新资源，再继承可读的主角选择及上次观看位置，清理属于本次安装的旧游戏文件。本机旧档实际保存了观看位置。
测试覆盖旧回放占用、更新时中断和重试、Windows 为同一目录提供两个路径、未知目录和玩家自存文件，以及未来游戏数据只影响部分入口的情况。已验证可自动补回缺失的原生库、替换损坏的元数据；剧本和编译记录同时损坏后也能重建，所得剧本 SHA-256 与首次成功结果一致。

角色、货币与存档
实机核对主角和同伴四维的写入、读回和还原。测试中主角 8 级力量由 8 调至 108，原作结算升至 9 级后力量为 109，原生存档保留额外加成 100。普通同伴魔法师的 SAN 可调整；勇者对 SAN 的修改保留 30，修改器显示实际值，并继续连接。
通过修改器依次测试正数、大额与零余额，核对游戏内显示及独立测试存档。一次写入 654321 后，测试存档的可花余额为 654321，累计获得量仍为原来的 792。
F8 实机将存活两人的当前生命从 1/44、1/35 回复到 23/44、18/35。其他队伍另测试了回复上限。使用 96 个真实存档文件的复制件测试完整备份、隐藏结局资格调整及恢复，恢复后 96 个文件逐一吻合。

自动检查与完整性
使用包内运行库执行 115 项 Python 自动测试，另执行 3 项原生资源往返测试。修改器侧通过 13 组 C# 测试，覆盖角色、货币、运行时兼容、存档、界面和回放启动。
本机 Steam 安装内 575 个文件和正式存档内 96 个文件的 SHA-256 与测试前逐一相同。正式压缩包另含逐文件 SHA256SUMS.txt。
